# TEMARI NET — Delivery Outcomes

- [x] **Mobile learner experience and account flows.** The app is branded TEMARI NET and supports Pre-K, Grade 1, Grade 2, Grade 3, and Grade 4. It presents student login and registration, a grade-level selector, editable API/server URL settings for a physical Android phone, and a gamified header with learner name, grade, streak, coins, and logout. The bottom navigation provides five distinct destinations: Quests, Speak & Read Studio, Temari AI, Leaderboard, and Rewards/Sponsorship. Quests can be filtered by All, Amharic, Math, English, and Science; cards are interactive and show completion/reward state. Quiz play reads the question with speech, presents four large child-friendly options, gives clear correct/incorrect feedback, and updates a newly earned coin balance immediately. Speak & Read lists Amharic Fidel and English vocabulary, offers “Listen” at 0.85x speech rate and “Practice Aloud” with practice-star feedback. Every Temari AI answer has a “Read Aloud” action. Leaderboard switches between the top 20 students and teachers and refreshes from the live API. The app offers a 50 ETB sponsorship action for Telebirr/CBE via an in-app browser or equivalent supported checkout handoff. Preserve Expo Router, React Native, TypeScript, NativeWind, project slug/scheme, and the starter-generated Android/iOS identifiers; do not replace the starter with `App.js` or change the Android package to `com.temarinet.app`.

- [x] **Authentication, account roles, and teacher referral rewards.** `POST /api/auth/register` hashes passwords, creates a student/teacher/admin account with full name, unique email, selected grade, default 50 coins and streak 1, returns a user and JWT, and if `registered_by_teacher_id` is supplied awards that teacher +10 coins within the same database transaction. `POST /api/auth/login` validates email/password and returns `{ user, token }`. `GET /api/auth/me` uses JWT middleware and returns live profile, coin, and streak values. Protect teacher/admin management operations with role-based access control for `student`, `teacher`, and `admin`; validate input and avoid trusting a client-supplied student ID for another user's rewards.

- [x] **Lessons, progress, gamification, and leaderboard.** `GET /api/lessons` returns lessons ordered by ascending ID and supports optional `?grade_level=` and `?subject=` filters. `POST /api/lessons/submit` accepts `{ student_id, lesson_id, selected_option }`, compares the selected option exactly with the stored `correct_answer`, and only when correct and not previously completed increments the student's coins by that lesson's reward and stores/upserts progress. It returns `{ correct, earnedCoins, correctAnswer, user }`; repeat completions do not award coins again. `GET /api/leaderboard?role=student` and `?role=teacher` returns up to 20 users of that role ordered by coins descending. Admin-created quizzes and mobile-earned coins are immediately visible to the other client and the leaderboard through shared persistence.

- [x] **Kid-safe AI and speech/practice flows.** `POST /api/ai/ask` accepts `{ question, studentName, gradeLevel }`, uses Gemini 2.5 Flash via `@google/genai` if a Gemini key is configured, and otherwise returns a deterministic local response without crashing. The tutor is “Temari AI, the friendly, safe, encouraging Ethiopian elementary school AI tutor inside the TEMARI NET app for children aged 5-11. Never discuss adult, violent, or off-topic subjects. Explain concepts simply in 2-3 short sentences using friendly emojis and occasional warm Amharic greetings like 'Selam' or 'Gobez' (Clever).” Speech playback works with the device speech engine; pronunciation/practice feedback is bounded to kid-safe learning and does not award lesson coins unless a quiz was correctly completed.

- [x] **Chapa sponsorship, local simulation, and verification.** `POST /api/chapa/initialize` accepts `sponsor_name`, `email`, `phone_number`, `amount_etb` defaulting to 50, and optional `student_id`; generates a unique `TEMARINET-TX-${Date.now()}-${random}` reference, stores a pending sponsorship, and calls `https://api.chapa.co/v1/transaction/initialize` with a bearer Chapa secret and customization title “TEMARI NET Sponsorship” when configured. If `CHAPA_SECRET_KEY` is absent or local demo mode is on, it returns `/api/chapa/mock-checkout?tx_ref=...` so the whole flow can be tested offline. `GET /api/chapa/verify/:tx_ref` verifies a real Chapa transaction or approves a mock checkout, idempotently marks the sponsorship completed, and awards +50 bonus coins to the selected student exactly once. `POST /api/chapa/webhook` validates `x-chapa-signature` with HMAC SHA-256 and `CHAPA_WEBHOOK_SECRET` before marking the transaction complete. Branded `GET /api/chapa/mock-checkout` and `/api/chapa/success-page` pages support simulated Telebirr/CBE Birr approval and a thank-you return display. Dashboard validates a 10-digit Ethiopian phone beginning 09 or 07, opens checkout in a new tab, and has a one-click transaction verification action that refreshes revenue and student coins.

- [x] **Administration and teacher portal.** `GET /api/admin/overview` returns total students, total teachers, total lessons, completed sponsorship revenue in ETB, recent users, lessons, and sponsorships. `POST /api/admin/lessons` creates a lesson; `DELETE /api/admin/lessons/:id` deletes a lesson; `DELETE /api/admin/users/:id` deletes a user, with role enforcement and appropriate referential behavior. Responsive single-page `admin-dashboard/index.html`, titled “TEMARI NET — Admin Control Center”, uses Tailwind CSS and FontAwesome and shows a live connection badge distinguishing API-connected from fallback/cache mode. Four KPI cards show students, active teachers, published quizzes, and sponsorship revenue (ETB). User & Teacher Management includes a form for student/teacher/admin creation with optional “Referred by Teacher ID”, a searchable table of name, role, grade, and coins, and a Delete action. Curriculum & Quiz Builder publishes Amharic/Math/English/Science quizzes with four comma-separated choices, exact answer, pronunciation word, coin reward, a live active-lesson list, and Delete action. Chapa 50 ETB Sponsorship Checkout & Verification includes sponsor name, email, Ethiopian mobile number, default amount 50 ETB and target Student ID. Dashboard displays honest connection/fallback status and refreshes shared values after mutations.

- [x] **Persistence and curriculum data.** The standalone PostgreSQL `database/init.sql` creates database/schema `temari_net_db`, drops only its listed local tables with `CASCADE`, creates users (`id`, `full_name`, unique `email`, `password_hash`, role constrained to student/teacher/admin, `grade_level` constrained to Pre-K/Grade 1/Grade 2/Grade 3/Grade 4, `coins` default 50, `streak` default 1, optional `registered_by_teacher_id` self-reference with `ON DELETE SET NULL`, `created_at`), lessons (`id`, `title`, `subject` Amharic/Math/English/Science, `grade_level`, `question`, JSONB four-string `options`, `correct_answer`, optional `pronunciation_word`, `reward_coins` default 15, `created_at`), progress (`id`, cascading `student_id` and `lesson_id`, score, completion time, unique `(student_id, lesson_id)`), and sponsorships (`id`, sponsor name/email/phone, `amount_etb` default 50.00, nullable student reference with `ON DELETE SET NULL`, status constrained to pending/completed/failed, unique `tx_ref`, timestamp). It seeds one admin `admin@temarinet.et`, one teacher `teacher@temarinet.et`, students `abebe@temarinet.et`, `hanna@temarinet.et`, `dawit@temarinet.et`, and six culturally relevant lessons covering Amharic Fidel ሀ, ለ, ሐ, መ, Math counting birr/fruits, English vocabulary, and Ethiopian wildlife/environment. Managed deployment mirrors the required behavior in additive MySQL/Drizzle TEMARI tables, without dropping or resetting shared starter tables; standalone PostgreSQL is supplemental and documented as a separate local path.

- [x] **Backend packages, runtime configuration, and resilience.** Provide modular Express backend package/configuration, `.env.example`, database pool and health check for `temari_net_db`, JWT/role middleware, route modules, and server entry. Local PostgreSQL backend listens on port 5000; managed WebDev API stays on fixed port 3000 and Metro on 8081. If `GEMINI_API_KEY` or `CHAPA_SECRET_KEY` is missing, deterministic local simulation responses are used and local testing does not crash. Keep secrets server-side; never expose them in app bundles or committed values. Additive managed schema migrations must preserve existing data.

Retain generated WebDev identifiers and the fixed managed Expo runtime while clearly documenting that the requested `com.temarinet.app` package and standalone EAS APK profile cannot replace those platform-owned settings in this project.
